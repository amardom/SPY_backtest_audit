# Offline XNYS session reference

Generated by `scripts/build_calendar.py` using exchange_calendars 4.13.2 in a
Python 3.12.3 tool environment. The exact installed package versions are recorded
in requirements.lock and manifest.json. The normal research command reads the
CSV with the standard library and does not install or query a calendar service.

Coverage: 2000-01-01 inclusive to 2022-01-01 exclusive. Early closes remain daily
sessions; intraday execution hours are not part of the audit. XNYS is a session
reference for this SPY study, not a claim that all source trades occurred on NYSE.

Source implementation and historical closure rules:
https://github.com/gerrymanoim/exchange_calendars
https://github.com/gerrymanoim/exchange_calendars/blob/master/exchange_calendars/exchange_calendar_xnys.py

The package's historical rules include special closures; the tests cover selected
closures and early-close dates. This is a versioned model-calendar check, not an
official exchange certification or proof of vendor price accuracy.

Regenerate in the documented tool environment, compare hashes, and review any
changed calendar before updating the validation freeze. Never regenerate silently
during normal research runs. Session dates contain no vendor prices.
